📝 Todo List App

![Live Demo](https://img.shields.io/badge/🚀_LIVE_DEMO-Click_Here-8b5cf6?style=for-the-badge)

A modern and responsive Todo List application built with HTML, CSS, and Vanilla JavaScript.

✨ Features
✅ Add, edit, and delete todos.
✅ Mark todos as completed or uncompleted.
✅ Filter tasks by status (All / Completed / Uncompleted).
✅ Save tasks using Local Storage.
✅ Responsive design for mobile and desktop.
✅ Double-click to edit tasks.
✅ Modern UI with smooth animations.

📥 Installation

1. Clone the repository:

bash
git clone https://github.com/negar-younesi/todo-list-app.git


2. Open the project folder:

bash
cd todo-list-app


3. Run the application:

Open index.html in your browser.

Or use a local server:

bash
python -m http.server 8000


Open http://localhost:8000 in your browser.

📖 How to Use
➕ Add Tasks
Enter your task in the input field.
Click the plus button or press Enter.
✏️ Edit Tasks
Double-click on a task.
Edit the text.
Press Enter or click outside to save.
✅ Manage Tasks
Click the checkmark to complete a task.
Click the trash icon to delete a task.
Use the dropdown menu to filter tasks.
💾 Local Storage

All tasks are automatically saved in your browser's Local Storage.

Your tasks remain available after refreshing the page or reopening the browser.
