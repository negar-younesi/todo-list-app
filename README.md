📥 Getting Started
Prerequisites
A modern web browser.
Git installed on your computer.
Installation

1. Clone the repository:

bash
git clone https://github.com/negar-younesi/todo-list-app.git


2. Navigate to the project directory:

bash
cd todo-list-app


3. Run the project:

Open index.html in your browser.

Alternatively, start a local server:

bash
python -m http.server 8000


Then visit:

http://localhost:8000

📖 Usage
➕ Adding Todos
Enter your task in the input field.
Click the plus button or press Enter.
✏️ Editing Todos
Double-click a task to edit it.
Press Enter or click outside the input to save changes.
✅ Managing Todos
Click the checkmark to complete a task.
Click the trash icon to delete a task.
Use the filter menu to view tasks by status.
💾 Local Storage

All tasks are automatically saved in your browser's Local Storage.

Your tasks remain available even after refreshing or reopening the browser.
